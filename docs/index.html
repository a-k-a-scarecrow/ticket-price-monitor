Ticket watchlist

Sign in with a GitHub access token to view and edit the watchlist.

  1. Open github.com/settings/personal-access-tokens/new
  2. Under Repository access, choose Only select repositories and pick ticket-price-monitor
  3. Under Permissions → Repository permissions, set Contents to Read and write
  4. Generate the token and paste it below

The token is stored only in this browser (localStorage) and is sent only to api.github.com. It's never sent anywhere else.
